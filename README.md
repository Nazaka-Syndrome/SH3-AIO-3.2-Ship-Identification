# 🚢 SH3 Ship Recognition - Web App (PWA)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-3.2-blue.svg)]()

Progressive Web App pour l'identification rapide des **224 navires marchands** de Silent Hunter 3 + Onealex Mod 3.2.

---

## ✨ Fonctionnalités

- 🔍 **Filtrage avancé** : Code M/F/K, position cheminée, superstructure, type, îles
- 🌍 **Multilingue** : Français 🇫🇷, Anglais 🇬🇧, Allemand 🇩🇪
- 🎨 **Thèmes** : Mode sombre et clair
- 📱 **Responsive** : Mobile, tablette, desktop
- ⚡ **Offline** : Fonctionne sans internet après première visite
- 💾 **PWA** : Installez sur l'écran d'accueil
- ♿ **Accessible** : Navigation clavier, ARIA labels

---

## 🚀 Installation Rapide
```bash
# Cloner le dépôt
git clone https://github.com/Nazaka-Syndrome/SH3-AIO-3.2-Ship-Identification.git
cd SH3-AIO-3.2-Ship-Identification
```

Ouvrir SH3 AIO 3.2 ID.HTML pour lancer l'application.
